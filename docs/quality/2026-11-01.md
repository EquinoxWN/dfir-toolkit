# Quality check against the 10 rules (2026-11-01)

Applied while building M1 (2026-11-09/10) on Windows 11 (Intel Core i7-13700H) with Python 3.14.5 in
the repo's `.venv`. Mutations were applied one at a time by a script that restores each file in a
`finally` block right after its test run.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | The only external call is the Volatility child process: per-plugin timeout (`subprocess.run(timeout=...)`), non-zero exit and start failure raise `VolatilityError` with the stderr tail, unparseable output raises `InputError`; each path is tested (fake Volatility: fail, garbage, hang; real Volatility on a non-image). It is not retried: a local, deterministic run would fail the same way. No network calls in the package; the CI download uses `curl --retry 3 --max-time 300` and a checksum. No swallowed exceptions in `src/`. |
| 2 | Writes safe to retry | pass | Reports go through `atomic_write_text` (temp file, fsync, `os.replace`); Volatility output goes to a partial file renamed only after it parses. Tests: re-write replaces, a failed rename keeps the old file, failed runs leave no file. Zips are never extracted. |
| 3 | No race conditions | N/A | Single-threaded; each plugin run writes its own file in the output directory. |
| 4 | Don't trust the clock | pass | Durations use `time.monotonic()` (CLI, runner); no stored timestamps are produced by the toolkit; times inside evidence are kept as the tools wrote them (UTC ISO 8601 from Volatility). |
| 5 | Read before changing | pass | No environment variables are read by the package (`TMP`/`APPDATA` only matter to Volatility, documented in the README). Every README link is checked by `audit_repo.py`. |
| 6 | Never break compatibility | pass | First release; the JSON report formats are documented in the README and covered by tests. The Volatility column contract is tested against the installed version. |
| 7 | One source of truth | pass | Plugin names and required columns live in `memory.REQUIRED_COLUMNS` and `volrunner.VOL_PLUGINS`; stack keys in `hunt.STACK_KEYS`, with a test that every shipped artifact has one. Python >=3.11 in `pyproject.toml`, CI and README. |
| 8 | Small changes, no secrets, validate input | pass | Secret grep: none; all fixtures synthetic. Inputs bounded: artifact files 256 KiB, JSON lines 1 MiB, zip members 512 MiB with a decompression cap, Volatility output 512 MiB, 50 M rows. ClientIds, PIDs, plugin names, fractions, host counts and timeouts are validated (argparse errors exit 2). |
| 9 | Tests that can actually fail | pass | Empty, invalid and failure paths covered in every module; 11/11 mutants killed (one after a new test). |
| 10 | Re-verify | pass | Results below; CI on push. |
