## Memory triage on the synthetic image (`dfir memory triage tests/fixtures/memory/injected`)

The fixtures are hand-written Volatility 3 2.28 JSON (same columns, banner and layout as `-r json`)
for a fictional Windows host: 19 processes in pslist, 21 in psscan. Planted: a Word document starting
encoded, hidden-window PowerShell; an `svchost.exe` started by explorer from `C:\Users\Public`; a second
`lsass.exe`; `scvhost.exe`; a PE image in private RWX memory of `notepad.exe` with an external
connection; shellcode-like bytes in `rundll32.exe`; an unlinked `updater.exe`; plus benign traps (an
exited process, an all-zero RWX page, a non-private image region, known-good names, internal

## Fleet stacking (`make bench`)

`dfir hunt synth` writes a seeded ProcessSnapshot hunt export: 20 baseline executables on every host,
four role packages on 10% to 30% of hosts, an older `sshd` build on 5%, kernel threads without an
executable, and two planted executables (`/dev/shm/.cache/kworkerd` on 2 hosts, `/tmp/.X11-unix/.sshd`
on 1). Every path and hash is invented.

| Fleet | Rows | Export size | Rare (<= 1% of hosts) | Time to read and stack |
|---|---|---|---|---|
| 1,000 hosts | 21,853 | 7.0 MB | 2, both planted | 0.27 s CPU (best of 3), 0.27 to 0.30 s wall |
| 10,000 hosts | 218,503 | 70.0 MB | 2, both planted | 3.28 s CPU, 3.9 s wall (best of 3); up to 20 s wall while nine other builds ran |

About 67,000 to 82,000 rows per second of CPU, one thread. The common software (including the 5%
`sshd` drift and the 10% role) never appears as rare.
